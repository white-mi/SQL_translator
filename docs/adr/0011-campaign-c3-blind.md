# ADR-0011: Кампания c3 - композиционный мир со слепой обратной связью

- Статус: accepted
- Дата: 2026-11-21

## Контекст

Кампания `sqltr-c2` остановлена оператором до того, как поиск набрал ход (одно предложение, baseline; $0.05). Причина - предсказуемость исхода: замер сложности на 750 свежих семьях ([probe](../../results/campaign/v2-difficulty-probe-2026-11-21.json)) показал, что победитель c1 переносится в композиционный мир на 0.931 (gp2trino 1.0 без единого изменения, trino2gp 0.863 с одним новым классом `DECIMAL(38,2)`-кастов). Композиция удлинила скрипты и усложнила семантику слабым решателям (у cand-27/29 - десятки mismatch), но чемпиону добавила один пункт в чек-лист: эволюция снова прошла бы класс за классом. Мир собирался из тех же парно-переводимых конструкций - локального правила по-прежнему достаточно для каждого фрагмента.

## Решение

- **Слепая обратная связь поверх композиционного мира** (выбор из B1/B2/стоп; ось данных уже сменена относительно c1, теперь меняем и ось обратной связи):
  - метрика получает `blind_feedback` (`metric_config.json`): провал отдаёт только счет и маркер `{"failure": {"kind": "blind"}}` - без класса ошибки, номера оператора, состояния и таблицы; успех - полную статистику;
  - обёртка `score_answer` ослепляет все пути (гейты, пустой ответ, сбой кандидата, кэш) одним местом, счет не меняется, поэтому METRIC_VERSION не поднимается;
  - замороженный пакет c3 собирается из `metric_config.blind.json` (оператор копирует его поверх `metric_config.json` на время freeze);
- **Данные - уже построенный и проверенный композиционный мир**: train `20261121` (self-check 250/250), public/private из сидов c2; новый ROOT `/srv/sqltr-arena-c3`, лимит 30, K=5, N=3, кап шлюза $2.5.
- Исследователь по-прежнему видит id провалившихся примеров и их входные скрипты и может офлайн-проверять синтаксис парсером в контейнере - это его собственные инструменты, не супервизия.

## Последствия

- Атрибуция «что убило поиск - данные или слепота» теряется (две оси против c1) - осознанная плата за максимум сложности при бюджете времени до ЧП3.
- Оба исхода - результат: быстрое закрытие мира значит «ярлыки избыточны, эволюция строит гипотезы сама»; останов на плато ниже 1.0 - «размеченная диагностика - необходимое условие». Провал автоматической проверки на слепых данных (`m-*` замер не двигается) лечится вентилем холостых ходов.
- c2 зафиксирован как «останавлив по решению оператора»: журнал с одним baseline-предложением и корень сохраняются, расходы $0.05.
