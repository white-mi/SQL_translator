# ADR-0006: Лимит предложенных решений и финалисты

- Статус: proposed (числа фиксируются после замера на ЧП1)
- Дата: 2026-11-01

## Контекст
Лимит числа решений - единственное ограничение поиска; его выбирает студент исходя из стоимости кандидата и ожидаемой сходимости.

## Решение
- Лимит - ориентир 50 решений, финалистов K = 5, итоговых N = 3.
- Обоснование: при 7-17 минутах на кандидата 50 кандидатов - 6-14 часов машинного времени; кэш метрики по хешу перевода сокращает время потомков; плато ожидаем после закрытия основных классов расхождений (около 30), в районе 30-40 решений.

## Альтернативы
- 100 решений, как в кейсах лаборатории: дольше, чем позволяют сроки курса при неизвестном времени Trino.
- 20 решений: не хватит, чтобы закрыть длинный хвост классов.

## Последствия
- После замера на ЧП1 статус меняется на accepted с фактическими числами; при медленном Trino уменьшаем public или направления (запасной сценарий в campaign.md).
