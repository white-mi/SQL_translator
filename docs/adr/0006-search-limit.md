# ADR-0006: Лимит предложенных решений и финалисты

- Статус: proposed (замер на стенде 8.11 числа подтверждает; лимит фиксируется командой `arena.sh journal`)
- Дата: 2026-11-01

## Контекст
Лимит числа решений - единственное ограничение поиска; его выбирает студент исходя из стоимости кандидата и ожидаемой сходимости.

## Решение
- Лимит - ориентир 50 решений, финалистов K = 5, итоговых N = 3.
- Обоснование: при 9-17 минутах на кандидата (замер на VM с 2 vCPU, `results/stand/full-train-2026-11-08.json`) 50 кандидатов - 8-14 часов машинного времени; кэш метрики по хешу перевода сокращает время потомков; плато ожидаем после закрытия основных классов расхождений (около 30), в районе 30-40 решений.

## Альтернативы
- 100 решений, как в кейсах лаборатории: 15-28 часов машинного времени и вдвое больше токенов исследователей, а плато ожидаем намного раньше.
- 20 решений: не хватит, чтобы закрыть длинный хвост классов.

## Последствия
- Замер 8.11 показал, что уменьшать public или направления не нужно; запасной сценарий остается в campaign.md. Статус меняется на accepted, когда лимит зафиксирован в журнале кампании.
