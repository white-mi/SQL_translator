# ADR-0002: Метрика - совпадение выходных таблиц на четырех состояниях данных

- Статус: accepted
- Дата: 2026-11-01

## Контекст
Нужна объективная программная метрика без LLM. Эквивалентность SQL-программ в общем виде не проверяется, сравнение текста переводов бессмысленно: одна и та же семантика пишется по-разному. Совпадение результатов на одной базе дает ложные срабатывания (Zhong, Yu, Klein, 2020).

## Решение
- Перевод исполняется на целевом движке на каждом из K = 4 состояний данных (обычные данные; NULL, ничьи и кириллица; граничные даты и большие числа; крошечные и пустые таблицы).
- Выходные таблицы сравниваются с эталоном как мультимножества строк: имена колонок без учета регистра и порядка, числа с точностью 1e-6, даты и время в одном формате. Сравниваются SHA-256 канонической формы.
- Пример получает 1, если все выходные таблицы совпали на всех состояниях, иначе 0. Итог - среднее по примерам; по направлениям строится разбивка.
- Гейты: пустой ответ, запись вне `wrk`/`sandbox`, `MERGE` для целевого диалекта Greenplum (его нет в Greenplum 7) - 0.
- Ошибка самого перевода (синтаксис, неизвестная функция, тип, нет прав, таймаут) - 0. Сбой инфраструктуры (движок недоступен, внутренняя ошибка хранилища) - ненулевой код выхода, то есть ошибка проверки, а не оценка.
- Изоляция: перевод выполняется под ролью без привилегий в схемах с уникальными именами, исходные данные доступны только на чтение.
- Для целевого диалекта Greenplum перевод исполняется на PostgreSQL 16 после удаления физических опций хранения (`DISTRIBUTED BY`, `appendonly`, встроенные партиции): они не меняют результат.
- Кэш по хешу (версия метрики, пример, перевод): метрика детерминирована, повторный перевод не пересчитывается.

## Альтернативы
- Сравнение текста или AST с эталонным переводом: штрафует верные переводы, написанные иначе.
- LLM-судья: шум и смещение, оценка невоспроизводима.
- Одно состояние данных: пропускает ошибки на NULL, пустых таблицах и граничных датах.
- Частичный балл за долю совпавших таблиц: вознаграждает частично неверный скрипт. Доля сохраняется в statistics для разбора.

## Последствия
- Эталонные переводы не нужны: эталон - результат исходного скрипта.
- Метрика ловит жульнические решения, это покрыто тестами: значения, зашитые по одному состоянию; выброшенные операторы; запись в исходные таблицы; MERGE для Greenplum; пустой ответ.
- Цена - исполнение на движке: около 0.06 с на пример на PostgreSQL, около 2.5 с на Trino (замер 8.11 на VM с 2 vCPU).
