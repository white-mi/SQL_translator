# ADR-0007: Модель - Claude Haiku 5.5

- Статус: accepted
- Дата: 2026-11-01

## Контекст
Правило курса 0-1: Intelligence Index модели на Artificial Analysis не ниже, чем у DeepSeek Flash на момент выбора. Модель нужна исследователям арены, а при модельном харнесе - решателю; у решателя и судьи модель одна и та же (судьи у нас нет).

## Решение
- Claude Haiku 5.5, уровень усилия Max: индекс 36 против 32 у DeepSeek V4.1 Flash 1017 (проверено 31.10.2026).
- Исследователь - Hermes в контейнере researcher арены. Подключение через OpenAI-совместимый прокси (LiteLLM) к API Anthropic, чтобы сохранить кэш промптов.
- Основная кампания - решатель без модели. LLM-харнес решателя подключается после приемки gateway арены.

## Альтернативы
- Модели курса (DeepSeek Flash): бесплатно, но общий доступ и возможная перегрузка.
- Более сильная модель (Sonnet): дороже в разы, а для исследователя такая сила не обязательна.

## Последствия
- В отчете фиксируются модель, версия, индекс и дата проверки.
- Расход - ориентир $20-100 за кампанию при кэше промптов; в консоли Anthropic ставится лимит расходов.
