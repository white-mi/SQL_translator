# Карта репозитория

Каждый файл репозитория: что это и кто его видит. Состояние проекта - в [README](../README.md#статус-на-811), все замеры - в [results/README.md](../results/README.md).

Метки:

- **[исследователь]** - файл копируется в workspace исследователя (`WORKSPACE_ALLOW` в `case/deploy/arena.sh`, ADR 0009). Все, что в нем написано, становится подсказкой поиску.
- **[только оператор]** - файл не должен попасть к исследователю: в нем правильные ответы, генератор или результаты пробы вне кампании.

Документация - на русском, код и комментарии - на английском.

## Что не в git

| Что | Где | Почему |
|---|---|---|
| Сгенерированные данные с эталонами (`data/train`, `data/holdout`) | на стенде | Воспроизводятся генератором; `instances.jsonl` содержит эталонные переводы |
| Пароли базы (`stand/.env`), настройки и сиды оператора | на стенде, вне репозитория | Секреты |
| Сырые результаты по примерам (`results/**/raw/`) | на стенде | Объем; сводки закоммичены |
| Код кандидатов пробы вне кампании | вне репозитория | Решатель растет только в кампании |
| `CLAUDE.local.md` | локально | Личные заметки |
