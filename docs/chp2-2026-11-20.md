# ЧП2: тезисы для синхрона (20.11.2026)

Статус одной фразой: стенд и арена работают, маршрут исследователя проверен на настоящей модели,
реальная кампания запущена сегодня утром и идет прямо сейчас (первые кандидаты в журнале,
baseline-якорь воспроизвел замер стенда: 0.064).

## Что могу показать вживую

1. **Стенд**: PostgreSQL 16.4 + Trino 483/Iceberg на одной VM, self-check парных рендеров
   250/250 на train и 12/12 на holdout, приемка развертывания арены 19/19.
2. **Метрика v2** (заморожена в кампании): исполнение на целевом движке по 4 состояниям данных,
   хеши таблиц без учета порядка; скрипт за лимитом ресурсов (temp_file_limit в PostgreSQL,
   память в Trino) получает 0 как дефект перевода, а не роняет серию (ADR 0002, 0008).
3. **Маршрут исследователя** (ADR 0007): ключ провайдера есть только у шлюза `gateway.py`,
   лимит в долларах переживает перезапуск, журнал вызовов без содержимого.
   Проверено по нарастающей: репетиция с фальшивым провайдером 22/22 → первый настоящий вызов
   `real_check.py` 8/8 (заголовки Hermes, thinking-блоки в tool-loop, кэш промптов работает) →
   капнутый тест на настоящей Haiku 5.5.
4. **Капнутый тест 20.11**: исследователь сам завершил поиск из 2 кандидатов за $0.076
   (~$0.04 на кандидата, пик памяти 169 МБ, ни одного запроса за ценовым порогом 100k токенов).
   Первый потомок (вырезание Greenplum-клауз из CREATE TABLE перед SQLGlot) поднял train
   0.064 → 0.196. Кандидаты теста в кампанию не идут - проверялась труба, не результат.
5. **Реальная кампания**: freeze (sha256 lock-файла 592692…973), public/private построены по
   секретным сидам оператора (по 100 семейств, вне git), журнал на 50 решений, K=5, N=3,
   readiness пройден. Первые записи: baseline зарегистрирован якорем кривой, его полный train
   через арену дал 0.064 - то же число, что без арены; cand-02 (правила для конструкций, которые
   SQLGlot не разбирает) в измерении сейчас.

## Решения, которые готов защищать

- **Усилие модели Medium, не Max** (ADR 0007, пересмотр 20.11): на Max суммаризация при сжатии
  контекста выдавала 22-128 тыс. выходных токенов на вызов, ход не завершался, темп $0.5/час;
  на Medium тот же поиск прошел за один ход. Правило 0-1 ограничивает модель (AAI 36), не усилие.
- **Решатель без модели** (ADR 0008): падение кандидата = 0 на примере, серия не роняется;
  тай-брейк по времени решателя.
- **Данные исследователю по разрешенному списку** (ADR 0009): без генератора, эталонов и holdout;
  артефакты подготовки оператора исследователю не видны - это норма, а не пробел (выяснено
  вживую 20.11 и зафиксировано в условиях).
- **Секреты**: сиды public/private и ключ провайдера только на VM оператора; репозиторий публичный
  с первого дня.
