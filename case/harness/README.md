# Харнес решателя

Немодельный харнес арены: образ `sqltr-runner:1` = комплектный `runner/main.py` арены + закрепленный SQLGlot 30.27.0. Кандидат - каталог с `solve.py` (и своими модулями), запускается без сети.

Регистрация у оператора (`ARENA_HARNESSES`, замораживается до кампании):

```json
{"sqltr-program": {"image": "sqltr-runner:1", "uses_model": false, "network": "none"}}
```

Модельный харнес (LLM-фоллбэк через gateway) добавляется отдельной записью после приемки gateway - см. ADR 0007.
