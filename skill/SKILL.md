# Перевод SQL-скриптов PostgreSQL/Greenplum ↔ Trino

Черновик: финальная версия собирается из выращенного на арене решателя после кампании.

## Когда использовать
- «Переведи этот скрипт с Greenplum на Trino» и обратно.
- Миграция витрин и ETL-шагов между PostgreSQL-совместимым MPP-хранилищем и lakehouse на Trino.

## Как использовать
```bash
python scripts/translate.py --from postgres --to trino script.sql > script_trino.sql
```
Вход - файл со скриптом (несколько операторов через `;`), выход - переведенный скрипт в stdout.

## Ограничения
Будут описаны по результатам разбора эволюции: классы конструкций, где перевод ненадежен.
